## What's new in 1.1.1

Scout 1.1.1 makes package lists and Details easier to scan, improves compact
layouts and keyboard access, and refreshes the documentation with realistic
mock sessions. It includes the changes merged since v1.1.0.

### More room for packages

- A single-cell selection marker replaces the padding before package names.
  `✓` marks a selected package, `◆` identifies the current selected row, and
  `●` identifies the current unselected row.
- Narrow tables prioritize package names and versions. Source stays compact
  and disappears before it can crowd upgrade versions.
- Empty-list messages remain readable after filtering a populated list.
  Long identifiers and paths wrap without losing their tails, and Help fits
  narrow terminals with keyboard scrolling.

### Details that focus on useful information

- Descriptions appear before secondary metadata. Details omits installer product
  codes, opaque family names, copyright, and repeated author/version values.
  Search shows a short tag summary; Installed and Upgrades omit tag lists.
- Compact link labels keep long URLs from consuming the pane. **More links…**
  in the action menu provides keyboard access to support, privacy, purchase,
  and documentation links. Links open their original destinations.
- Review and result rows show status, package name, and reason. Source or ID
  appears only when needed to distinguish packages with the same name.
  Status labels align, review buttons fit, and backend errors display literally.

### Updated rendering and realistic demonstrations

- Update Terminal.Gui from `2.5.1-develop.89` to `2.5.1-develop.171`, including
  Windows supplementary Unicode input, Markdown partial-redraw, and nested-dialog
  shutdown fixes. The final `.170` to `.171` increment changes upstream tests only.
- Replace synthetic mock metadata with a frozen snapshot of 23 real catalog
  entries, including 18 installed packages and 14 available upgrades. Each mock
  session gets its own data; observed version choices are newest-first.
- Refresh all four theme screenshots and both workflow GIFs with the new data.
  Demonstrations review plans and cancel them without changing real packages.

Validation includes 749 automated tests, Windows ARM64/x64 Native AOT builds,
mock smoke checks, and read-only ARM64 COM diagnostics. Native Windows Terminal
keyboard/mouse/resize behavior remains unverified. Native ARM64 COM installs
remain a [known limitation](https://github.com/harder/wingetscout/blob/main/docs/architecture.md#known-com-limitations);
use the CLI backend for affected operations.
