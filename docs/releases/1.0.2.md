
## What's new in 1.0.2

- Package lists keep keyboard focus when arrows or paging keys reach either
  end, including empty lists. `Tab` and `Shift+Tab` still move between panes.
- `j`/`k`, filtering, and refreshed selections keep the selected package visible
  when navigating a scrolling list. `Home` and `End` jump to the first and last
  package.
- Version pickers and other package dialogs handle empty lists safely.
- Terminal cleanup is attempted even if the run loop or window disposal fails.
  Error reports preserve stack traces and inner exceptions after cleanup.
- The website and documentation now describe the navigation behavior and the
  pending community WinGet submission.

This is a Windows maintenance release. It does not change the known ARM64 COM
installation and architecture-selection limitations described in the
[architecture guide](https://github.com/harder/wingetscout/blob/main/docs/architecture.md#known-com-limitations).
