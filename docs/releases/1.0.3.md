## What's new in 1.0.3

- Updated Terminal.Gui to `2.5.1-develop.89`, including improvements to terminal
  startup probes and redraw after late terminal-color responses.
- Background UI updates now use Terminal.Gui's awaitable dispatch. Scout keeps
  cancellation and stale-result safeguards while preserving callback failures
  during shutdown.
- Failed WinGet COM queries report their status and error instead of appearing
  as empty package lists. Successful queries with no matches remain valid.
- Added a read-only `--comsmoke` diagnostic for COM inventory, search, package
  details, versions, and installer previews. `--comdiag` now returns a failure
  exit code when activation fails.
- Dependency monitoring checks every NuGet registration page and selects develop
  candidates by publication date, avoiding misleading version-number ordering.

This is a Windows maintenance release. The WinGet COM packages remain at
`1.29.380`. Known ARM64 COM installation and architecture-selection limitations
remain; see the
[architecture guide](https://github.com/harder/wingetscout/blob/main/docs/architecture.md#known-com-limitations).
